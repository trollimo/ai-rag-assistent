# Частые проблемы и формулировки для комментария в PR

## Нет лимитов ресурсов

> В `deployment.yaml` контейнер `<имя>` не задаёт `resources.requests`/`limits`.
> Без них под может исчерпать ресурсы узла и вытеснить соседние поды.
> Добавьте оба поля — ориентир можно взять из соседних сервисов.

## Нет readiness/liveness probe

> У контейнера `<имя>` отсутствует `readinessProbe`. Без неё Service начнёт
> слать трафик на под ещё до его готовности — добавьте probe на `/health`
> или аналогичный эндпоинт.

## Тег latest

> Образ `<image>:latest` не откатываем — при следующем деплое подтянется
> непредсказуемая версия. Замените на фиксированный тег/digest.
