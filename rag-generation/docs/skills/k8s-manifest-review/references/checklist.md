# Чеклист проверки манифеста

| Проверка | Почему важно |
|---|---|
| `resources.requests`/`limits` заданы | без них под может занять весь узел или быть вытеснен непредсказуемо |
| `livenessProbe`/`readinessProbe` есть | иначе оркестратор не отличит зависший под от рабочего |
| `selector.matchLabels` = `template.metadata.labels` | несовпадение — Deployment не увидит свои поды |
| образ не `:latest` | невозможно откатиться на конкретную версию |
