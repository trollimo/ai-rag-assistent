# PR Checklist Skill

Version: 1.0

Скилл для быстрой самопроверки Pull Request перед тем, как отправить его на
ревью человеку. Не заменяет ревьюера — отсеивает механические замечания
(забытые логи, отсутствие тестов, неочищенные TODO), чтобы ревью человека
уходило на суть, а не на формальности.

## Когда применять

Перед созданием PR или сразу после его открытия — прогнать изменённые файлы
по `checklist.md` и отметить каждый пункт.

## Как использовать

1. Получить список изменённых файлов (`git diff --name-only main...HEAD`).
2. Пройтись по `checklist.md` пункт за пунктом.
3. Для каждого невыполненного пункта — либо исправить, либо явно обосновать
   в описании PR, почему он не применим.
4. Не отмечать пункт выполненным, если не уверен — лучше явно написать
   "не проверено".
